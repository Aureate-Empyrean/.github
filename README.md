# Aureate Empyrean

**Open software. Private by design.**

Aureate Empyrean is an open-source ecosystem of self-hosted software built around a simple idea:

**Your data should belong to you.**

We're building interoperable tools that can run on infrastructure you control, work together as one ecosystem, and remain useful without artificial paywalls, mandatory cloud accounts, or data harvesting.

## The Ecosystem

### Empyrean Nexus
The foundation connecting Aureate Empyrean.

Nexus provides the shared infrastructure that allows independent modules to work together as a single ecosystem — identity, APIs, events, permissions, storage, integrations, and module management.

### Meridian Ledger
A comprehensive people and relationship knowledge system.

Built for organizing the people in your life, relationships, interactions, history, facts, notes, sources, timelines, and the knowledge accumulated around them.

### Atlas
Private location history and places.

### Mnemosyne
Knowledge, notes, memories, and connected information.

### Argus
Photos, media, metadata, and recognition.

### Hermes
Communications and conversation history.

### Chronos
Calendar, events, dates, and personal timelines.

## Principles

- **Open source**
- **Self-hosted**
- **Privacy by design**
- **Local-first where possible**
- **Interoperable, not isolated**
- **Open APIs and portable data**
- **No artificial paywalls**
- **No data harvesting**
- **No mandatory cloud dependency**

Aureate Empyrean is being built as a collection of focused projects rather than one enormous application.

Each module can have its own purpose and repository while sharing the same foundation through Empyrean Nexus.
